# Zamzam Foods — Client Desktop Installation Guide

## 1. System Requirements

- **Windows**: Windows 10 or Windows 11 (64-bit).
- **macOS**: macOS 11.0 Big Sur or later (Apple Silicon M1/M2/M3/M4 & Intel).
- **Network**: Active Internet connection to communicate with the cloud backend API.
- **Local Database**: **None required**. No PostgreSQL, MySQL, or XAMPP installation is needed on client machines.

---

## 2. Windows Installation (`.exe` / Setup)

1. **Download**: Obtain `Zamzam Foods Setup.exe` from the authorized release folder.
2. **Run Installer**:
   - Double-click `Zamzam Foods Setup.exe`.
   - The setup wizard will guide you to select the installation directory (default: `%LocalAppData%\Programs\ZamzamFoods`).
3. **Desktop Shortcut**:
   - The installer creates a desktop shortcut and a Start Menu entry.
4. **Launch**:
   - Double-click the **Zamzam Foods** desktop shortcut.
   - Enter your staff or owner PIN / credentials to begin billing immediately.

---

## 3. macOS Installation (`.dmg`)

1. **Download**: Obtain `Zamzam Foods.dmg` from the release folder.
2. **Mount Disk Image**:
   - Double-click `Zamzam Foods.dmg`.
3. **Install**:
   - Drag the **Zamzam Foods** application icon into your **Applications** folder.
4. **Launch**:
   - Open **Zamzam Foods** from Applications or Spotlight.
   - Log in using your business credentials.

---

## 4. Multi-Terminal Synchronization

- All changes (new orders, invoices, payments, customer balances) synchronize **instantly** through the cloud.
- If a cashier records a payment on a Windows terminal, the owner viewing the dashboard on a Mac or mobile device sees the updated balance immediately.
- Zero local network or local database sharing configuration is required.
